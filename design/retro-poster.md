# Оформление: «ретро-плакат космической гонки»

Направление для Apolune. Референс — интерфейс Star Wars: Galactic Racer (Game UI Database, id 2583):
бумага, дуотон, диагональные ленты, тяжёлый капс, приборная мелочь моноширинным.

Берём **систему**, а не картинки: арты, логотипы и шрифты правообладателя не используем.

Все четыре — OFL и с кириллицей. Платная альтернатива дисплею — Druk.

## Форма и фактура

- Карточки — радиус 12, капсулы — 999, волосяные линии 1 px тушью при 12% прозрачности.
- Диагональ лент — 14–20°, три-четыре полосы (олива, золото, красный, бумага).
- Зерно — тайл 256×256 поверх фона, 4–6%.
- Орбитальные окружности — 1 px, тушь 7%, за кадром по краям.
- Тени печатные: смещение 5 px без блюра, тушь 18%.

## Экраны

**Онбординг.** Плакат: `APOLUNE`, схема орбиты с точкой на дальней стороне, капсула «ПРИНЯТЬ И ПРОДОЛЖИТЬ».

**Главный.** Постер сервера (планета в дуотоне, ленты в нижней трети, штамп статуса под −6°), справа
состояние, моно-таймер, трафик, маршрут `127.0.0.1 → узел → ИНТЕРНЕТ`, капсулы действий, справа билет подписки.

**Серверы.** Сетка карточек 2:3, у каждой своя лента и свой дуотон; задержка моно в правом нижнем углу.

**Подписка.** Билет с перфорацией, штамп «АКТИВНА», barcode, срок крупной цифрой, трафик — шкалой
из 12 делений.

**Настройки.** Список на бумаге, волосяные разделители, значения моно, переключатели-рычаги.

## Движение

180–220 мс, `cubic-bezier(0.2, 0, 0, 1)`. Карточка приподнимается на 2 px с печатной тенью;
смена экрана — сдвиг + проявление; штамп появляется с доворотом на 3°.

## Чего не делать

Неон, glassmorphism, градиентные свечения, скругления больше 16, иконки-эмодзи. Никаких
материалов правообладателя.

## Реализация

- тема: `lib/pages/theme/` (палитра, типографика, форма карточек);
- шрифты: `assets/fonts/` + `pubspec.yaml`;
- ленты, орбиты, перфорация — `CustomPaint`;
- зерно — PNG-тайл в `assets/`.

Прототип главного экрана: `design/prototype` (отдельное Flutter-приложение в этой ветке).
Скриншот — `onekey/observer/apolune-poster.png`.
